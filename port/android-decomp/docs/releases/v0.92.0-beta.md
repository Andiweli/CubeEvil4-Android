# CubeEvil4 v0.92.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

## New

- European discs: CubeEvil4 now also plays the European release (Disc 1 and 2, G4BP08) next to the debug build.
- Game language for the European discs in the in-game menu: English, Deutsch, Français, Español, Italiano (default: your phone's language; changing it restarts the game).
- Gyro aiming can be inverted vertically and horizontally (in-game menu → Controls).
- If the game cannot read a disc file, it now names the file and tells you what to do instead of freezing.

## Fixed

- The import now checks every file against the original disc and reads each file back, so a damaged image or a file the phone did not store correctly is reported right away.
- With the European discs: the radio call's dark subtitle bar and Hunnigan's picture, the option screen's help texts, the life meter's name, the map (rooms, arrow, no stray merchant icon) and the room texts of r221 are right.
- After using the key in r101 the game now says "You used the …" instead of a text about a shelf.

## Changed

- With the European discs, holding SELECT opens nothing (the debug menu belongs to the debug build).
- The title menu of the European discs shows START, LOAD, OPTIONS; the language is chosen in the in-game menu.

## Known issues

- Saves are shared between the debug build and the European discs; tested on the PC in both directions, not yet on many phones.

## Update

Install `CubeEvil4-v0.92.0-beta.apk` over v0.91.0; discs, saves and settings stay. For the European discs
import both of them (start screen, "Import Disc 1" and "Import Disc 2"); both discs must be of the same release.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
