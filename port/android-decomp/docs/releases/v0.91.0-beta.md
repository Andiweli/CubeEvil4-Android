# CubeEvil4 v0.91.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

## Fixed

- The glow of torches and the merchant's fire no longer shines through walls (the game's own hide-behind-wall check gets the picture's depth now).
- Dark wavy bands at the bottom of the screen in the intro and in water scenes are gone.
- A Ganado kicked against a closed door can no longer fly through it (house in the village).
- A damaged room file no longer freezes the game without a word: the game reads it again, then says "DISC FILE DAMAGED". The app checks the room files against the original disc after an import and on every start and tells you if one differs (import the disc again).
- 32-bit phones with little free memory: room modules are loaded into reserved address space (crash at the first room).
- The debug menu's SCE ITEM tool no longer crashes.
- Fast tapping counts every tap: "Press A rapidly" (the run from the Salazar statue) no longer merges quick taps into one long press.

## New

- Instant save and load in the menu: Save and Load at the current spot, besides the typewriter. Refused where it would trap you (boat, ladder, boss fights, Mercenaries, Ashley sections).
- FXAA switch (menu → Display, under MSAA): smooths edges in a last step, with or without MSAA.
- Frame skip (menu → Performance): when the graphics cannot keep up, a picture is skipped so the game keeps its normal speed.
- The touch controls' editor can add the C stick as four buttons (C↑ C↓ C← C→).
- The error report lists your controllers (controllers.txt) and the log names every button or axis the app does not know.

## Changed

- New menu in five pages (Home, Display, Controls, Performance, Management) with buttons instead of radio buttons, in 10 languages.
- Row labels in the menu are centred next to their buttons.

## Update

Install `CubeEvil4-v0.91.0-beta.apk` over v0.90.x; discs, saves and settings stay. If the start screen
says room files differ from the original disc, import that disc again.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
