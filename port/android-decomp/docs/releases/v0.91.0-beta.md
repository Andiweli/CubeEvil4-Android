# CubeEvil4 v0.91.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

## Fixed

- 60 FPS no longer slows the game down: in-between pictures are much cheaper and are left out when the graphics fall behind.
- The glow of torches and the merchant's fire no longer shines through walls, also after changing the resolution.
- With 60 FPS, the list at the typewriter and in the menus no longer flickers while it scrolls.
- With 60 FPS, smoke, fog and fire no longer flicker or jump around.
- Dark wavy bands at the bottom of the screen in the intro and under water are gone.
- Changing the graphics options no longer leaves some effects without their texture until the next room.
- "Press A rapidly" (the run from the Salazar statue) counts every fast tap instead of merging them into one long press.
- A Ganado kicked against a closed door no longer flies through it (house in the village).
- A damaged room file no longer freezes the game: it is read again, then "DISC FILE DAMAGED" is shown.
- 32-bit phones with little free memory no longer crash at the first room.
- The debug menu's SCE ITEM tool no longer crashes.

## New

- Instant save and load in the menu, also loadable from the title screen; refused where it would trap you (boat, ladder, boss fights, Ashley sections, Mercenaries).
- New menu in five pages (Home, Display, Controls, Performance, Management) with buttons, in 10 languages.
- FXAA switch (Display, under MSAA) smooths edges, with or without MSAA.
- Frame skip (Performance) skips a picture when the graphics fall behind, so the game keeps its normal speed.
- The touch controls' editor can add the C stick as a yellow analog stick (ADD, then ACTION until "C").
- The app checks the room files against the original disc after an import and at every start and warns if one differs.
- The error report lists your controllers, and the log names every button or axis the app does not know.

## Changed

- 60 FPS and frame skip can no longer be on together: switching one on switches the other off.
- Dynamic resolution also steps down with 60 FPS when the GPU cannot keep up.
- The app knows 9006 shaders instead of 8068, so fewer effects stutter the first time.
- Analog triggers press L/R at 85 % and let go below 70 %, so a trigger held near the click no longer flickers.
- The debug menu (hold SELECT) shows only AREA JUMP and DEBUG OPTION, at the left edge, without the flickering bars.

## Update

Install `CubeEvil4-v0.91.0-beta.apk` over v0.90.x; discs, saves and settings stay. If the start screen
says room files differ from the original disc, import that disc again.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
