# CubeEvil4 v1.0.0

> The whole game can be played from start to finish. Keep a copy of your saves (app menu → Management → Export
> Player Data (.zip)).

Changes since v0.99.18.

## Fixed

- View distance "Far" looked the same as "Normal" in most places while it drew up to twice as much.
- Alternate controls: the rifle scope could not zoom; now the left stick up/down zooms while you aim.
- Cheat "Random enemies" barely moved anyone: ordinary Ganados now start at random places anywhere in the room they can walk, in many more rooms.
- Small frame drops on some 120 Hz phones (for example Xiaomi with LTPO screens): the app misjudged the screen's refresh rate and switched its frame pacing off.
- 30 FPS on 90 Hz screens without a 60 Hz mode now keeps a steady rhythm (three refreshes a picture).
- 60 FPS: phones that slow down when warm now stay at a steady 30 for longer instead of switching back and forth every few seconds.
- Cheat "Invisibility": enemies that wait at their post (for example the Zealot with the key in the castle) stayed invisible and could not be hit; they now appear as usual and can be killed.

## New

- Cheat "Steady aim": the laser sight and the rifle scope no longer sway while you aim.
- Touch controls: an aim stick and a knife stick you can add in the editor (gear), with their own icons: a finger on it readies the weapon or knife, tilting it aims, the other thumb fires. One layout now holds the move stick, the C stick and both of them.
- Touch controls: two new button styles, PS2 and XBOX, and a new GC style with the GameCube's shapes and colours; switch with the style button in the editor (gear) or under Controls → Button style.
- Option "Turn Leon with mouse / look area": moving the mouse or swiping the touch look area sideways turns Leon directly, as in the PC mods.
- Sideload APK: keeps the game data in a folder of your choice outside Android/data, for example on an SD card (start screen → Data folder; needs "All files access").
- Cheat "Costumes · Leon's jacket": Leon keeps his brown jacket from chapter 1 for the whole game.
- Option "Sharper menu text": the game's own menu words are drawn sharper on high resolutions, in every language (on by default).
- HD textures: "Costumes" and "Weapons" on the Mods page keep the game's own textures for the playable characters or the weapons, even with a texture pack (default: texture pack).
- Real-time shadows (Display): Leon, Ashley, the enemies and moving objects cast shadows from the game's own lights (sun, torches, lamps, candles, lightning), up to three at once; on by default only on strong devices. Under lamps (castle halls) they no longer get too dark and no longer flicker or pop in and out when the camera turns; huge shadows from a lamp right next to a character fade out; the game's fill lights from below no longer throw shadows up walls and ladders.

## Changed

- Cheats page: "Player" now holds all player switches (Costumes included), "General & inventory" also has the Attaché case L and +1,000,000 PTAS, and the character choice is a grid (Leon, Ada, HUNK / Krauser, Wesker).
- The help texts in the app menu are shorter and keep only what you need to know.
- View distance "Far" now moves the fog itself further away, so you see clearly further in the forest, at the lake, in the castle and on the island; it draws more and costs the most.
- View distance "Medium" is a bit shorter (65 % instead of 75 %), so the levels differ more clearly.
- The app menu's "Source and updates" now says that CubeEvil4 for Android and OUYA/Potato is only available there: avoid other sites and game platforms.
- Cheats: "Special costumes" is now "Costumes" (Normal / Leon's jacket / Special), one button that moves on with each press.
- Vulkan is no longer marked experimental; OpenGL ES stays the default.
- HD textures: all menus keep the game's own words and font (the pack redrew only some menu words, so menus looked mixed).
- RetroTouch updated to 1.0.0-beta.13 (new button shapes, a four-button D-pad, labels on the sticks, labels exactly centred).
- License: CubeEvil4's own port code is now under the GPL-3.0 (with an exception for the game's original code): whoever shares a modified build must share its source too; code published before 1.0.0 keeps the terms it was published with (CC0).

## Known issues

- 60 FPS (experimental): big torch flames can still flicker now and then.
- Vulkan: right after installing, while the pipelines are still being built in the background, and in places the app's list does not know yet, a scene can stutter the first time it appears. Vulkan needs Android 10 or later.
- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).
- Invisibility: bosses and scripted attacks still happen.
- Player characters other than Leon (Ada, HUNK, Krauser, Wesker) are not made for the main game: bugs will occur with them.
- Cutscenes keep their letterbox with the picture format "4:3".
- The sound can have a short gap now and then (shots, the ending movie on some devices).
- Debug build's discs: Ashley can walk through the armor statues (the prototype's data has no collision there).
- Some controllers' left stick can make Leon stutter while walking (the D-pad does not): try a higher stick range or dead zone; if it still stutters, walk with the stick for 30 seconds and send a report.
- Phones with only small processor cores (for example Samsung Galaxy A13): the game runs slower than normal, so cutscenes run behind their voices. Frame skip Normal cannot help there; Frame skip Aggressive may (not yet tested on such a phone).
- A resolution higher than the GPU manages (for example 3.5x or 4x on a Mali-G57) slows the whole game down and makes the sound crackle: use Dynamic or the level the benchmark found.
- A save that was imported with an older version and then saved again in the app keeps the mixed-up rooms (apart from the Garrador): import the original .gci again to get them back.
- Some phones (for example Samsung, Xiaomi, Motorola) keep apps off the camera hole with a setting of their own: if a black strip stays on the camera's side, let CubeEvil4 use the full screen there (often under Display, as "Camera cutout" or "Full screen apps").

## Update

Install `CubeEvil4-1.0.0-Android.apk` over an earlier version; discs, saves and settings stay. To keep the data
in a folder of your choice, install `CubeEvil4-1.0.0-Android-sideload.apk` instead: it is the same app and installs
over the normal one and back.

**HD textures (optional):** the CubeEvil4 Texture Packer 1.4 comes as files of its own with this release. All
read your own Dolphin texture pack as a folder or a ZIP file, with DDS (BC1–BC5, BC7, uncompressed), PNG and JPG
images, and make the same `.c4tex` file. Sizes: 256 (weak devices, about 0.3 GB), 512 (recommended, about 0.7 GB)
or 1024 (strong devices, about 2.3 GB); no image gets smaller than the game's own.

- Windows: `CubeEvil4-TexturePacker.exe` (no installation). Double-click it, drag the pack's folder or ZIP file
  into its window, choose a size and where to save; it shows the progress and a summary. Copy the `.c4tex` file to
  the phone and import it under app menu → Cheats & Mods → Mods. `CubeEvil4-TexturePacker-Console.exe` does the
  same on the command line.
- Android: install `CubeEvil4-TexturePacker-1.4.apk` (Android 7 or later), choose the pack's ZIP file or folder and
  a size, then Start (a phone needs far longer than a PC: keep it on the charger). The file is saved in the
  Download folder; "Import into CubeEvil4" hands it straight to CubeEvil4.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
