# CubeEvil4 v0.93.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

Changes since v0.91.0 (including v0.92.0).

## New

- European discs: CubeEvil4 now also plays the European release (Disc 1 and 2, G4BP08) next to the debug build.
- Game language for the European discs in the in-game menu: English, Deutsch, Français, Español, Italiano (default: your phone's language).
- Cheats in the in-game menu (Management): infinite health, infinite ammo, one-hit kill, and buttons for a fully upgraded Killer7, the attaché case L and +1,000,000 PTAS.
- Controller configuration (in-game menu → Controls, with a controller connected): X, Y, L1, R1, L3 and R3 can take any function; A, B, L2, R2, START, SELECT and the D-pad stay as they are, so the game's button prompts always match.
- Resolution in half steps: 1.5x, 2.5x and 3.5x, also for the dynamic resolution.
- Gyro aiming can be inverted vertically and horizontally.
- If the game cannot read a disc file, it names the file and tells you what to do instead of freezing.

## Fixed

- The disc import checks every file against the original disc and reads it back, so a damaged image is reported right away.
- European discs: the rooms of the fourth stage (among them The Mercenaries) load instead of stopping with a disc error.
- European discs: radio call subtitle bar and Hunnigan's picture, option help texts, life meter name, map and room texts are right.
- European discs in English: no stray "14-09LE" subtitle in cutscenes.
- European discs: the merchant's mark on the castle map moves with him.
- The dynamic resolution steps down when the graphics chip falls behind, so heavy scenes like rain stutter less.
- After using the key in r101 the game says "You used the …" instead of a text about a shelf.

## Changed

- Stronger and longer rumble.
- Cheat buttons light up briefly when pressed.
- European discs: holding SELECT opens nothing (the debug menu belongs to the debug build); the title menu shows START, LOAD, OPTIONS.

## Known issues

- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).

## Update

Install `CubeEvil4-v0.93.0-beta.apk` over v0.91.0 or v0.92.0; discs, saves and settings stay. For the European
discs import both of them (start screen, "Import Disc 1" and "Import Disc 2"); both discs must be of the same release.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
