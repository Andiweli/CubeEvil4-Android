# CubeEvil4 v0.93.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

## New

- Controller configuration (in-game menu → Controls, with a controller connected): X, Y, L1, R1, L3 and R3 can take any function; A, B, L2, R2, START, SELECT and the D-pad stay as they are, so the game's button prompts always match.
- Resolution in half steps: 1.5x, 2.5x and 3.5x next to 1x to 4x, also for the dynamic resolution.

## Fixed

- With the European discs, the rooms of the game's fourth stage (among them the maps of The Mercenaries) now load instead of stopping with a disc read error.
- With the European discs in English, cutscenes no longer show the stray subtitle "14-09LE".
- With the European discs, the merchant's mark on the castle map moves with him, as in the original.
- The dynamic resolution now also steps down when the graphics chip falls behind, so heavy scenes such as rain stutter less.

## Changed

- Stronger and longer rumble.
- The cheat buttons light up briefly when pressed.

## Known issues

- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).

## Update

Install `CubeEvil4-v0.93.0-beta.apk` over v0.92.0; discs, saves and settings stay.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
