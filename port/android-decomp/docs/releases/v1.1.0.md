# CubeEvil4 v1.1.0

> Keep a copy of your saves (app menu → Management → Export Player Data (.zip)).

Changes since v1.0.0.

## Fixed

- Vibration did nothing on many devices and controllers: the game's own vibration switch was off in most save files; it now follows the app menu's "Vibration" (on unless set to Off), and switching it in the game's options changes the app's setting too.

## New

## Changed

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
