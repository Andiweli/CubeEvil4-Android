# CubeEvil4 v0.96.2 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

Changes since v0.96.0.

## Fixed

- Castle, dragon hall over the lava: the chains of the dragon platforms break again after a few hits, as in the retail game.
- Assignment Ada: finishing it now unlocks the Chicago Typewriter at the merchant.
- European discs on Easy: walking through the archway after the cannon (the reunion with Ashley) no longer crashes the game.
- 32-bit phones: no more crash ("bus error") when changing rooms.
- US discs: the armor statues in Ashley's room leave no invisible walls once the knights come alive.
- Controller with your own button mapping: holding a button while a menu opens or closes no longer counts as a second press.
- The Mercenaries: the stage select shows the characters' icons only once they are unlocked.
- Russian: corrected text for the dynamic resolution (thanks to a tester).

## New

- US retail discs (G4BE08) can be imported and played.
- Auto aim (Controls page): when you raise your weapon, the aim jumps to the nearest enemy in front of you, with every gun.
- Always run (Controls page): Leon runs whenever you move; hold the run button to walk.
- Merge draw calls (experimental, Performance page): may help phones with slow graphics drivers; off by default and not active while 60 FPS is on.

## Changed

- Fewer stutters when entering a room: the game prepares its graphics programs much faster on the title screen, in menus and while loading.
- App menu: buttons side by side have the same gap as between rows.
- Error report: the "heap 4" line when the game loads a cutscene through extra memory no longer reads like an error.

## Known issues

- 60 FPS (experimental): big torch flames can still flicker now and then.
- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).
- Cutscenes keep their letterbox with the picture format "4:3".
- The sound can have a short gap now and then (shots, the ending movie on some devices).
- Debug build's discs: Ashley can walk through the armor statues (the prototype's data has no collision there).

## Update

Install `CubeEvil4-v0.96.2-beta.apk` over an earlier version; discs, saves and settings stay.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
