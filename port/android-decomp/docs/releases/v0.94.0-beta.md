# CubeEvil4 v0.94.0 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Savegames).

## Fixed

- The Mercenaries with HUNK no longer crashes the app, on every map.
- European discs: the chapter end shows the enemies killed with four digits; no digit keeps changing in front.
- European discs: the opening movie shows its subtitles (German, French, Spanish, Italian; English has none, as on the GameCube).
- 60 FPS: no stray "%" between the rows of the chapter end, and no white flash when START opens the options.

## New

- 60 FPS: the in-between pictures follow every object of the game itself, so torches, smoke, sparks and moving textures (water, lava) flicker much less.

## Changed

- 60 FPS: when the graphics chip cannot keep up, the in-between pictures pause for a few seconds (an even 30) instead of switching between 60 and 30.
- European discs: the game end screen counts continues up to 999, as the European release does.

## Known issues

- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).

## Update

Install `CubeEvil4-v0.94.0-beta.apk` over an earlier version; discs, saves and settings stay.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
