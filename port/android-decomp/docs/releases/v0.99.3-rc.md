# CubeEvil4 v0.99.3 (Release Candidate)

> **Release Candidate.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Management → Export Player Data).

Changes since v0.99.2.

## New

- Potato mode → Particle effects (Normal, Less, None): fewer blood, dust, smoke, splash and spark effects for weaker devices; fire and explosions stay visible as a warning, and so does the spot where a shot hits.
- Potato mode → Shadows & light: off leaves out shadows (also in cutscenes), lens glows and light shafts; the rooms keep their lighting.
- Display → Renderer: Vulkan (experimental) next to OpenGL ES; it can be faster on some devices, Mali GPUs above all.
- If Vulkan cannot start or the game ends while it starts, the game goes back to OpenGL ES and says so.
- The error report names the renderer, the GPU and its driver.

## Changed

- Cheats → Player character: choosing a character other than Leon first shows a warning that these characters are not made for the main game and bugs will occur; “I understand” switches, Back keeps your character.

## Known issues

- 60 FPS (experimental): big torch flames and fog banks can still flicker now and then.
- Vulkan (experimental): the first time a scene appears it can stutter while its shaders are built; from then on it runs smoothly. Vulkan needs Android 10 or later.
- Infinite health does not stop the instant deaths of some attacks (chainsaw, grabs, boulders).
- Invisibility: bosses and scripted attacks still happen.
- Player characters other than Leon (Ada, HUNK, Krauser, Wesker) are not made for the main game: bugs will occur with them.
- Cutscenes keep their letterbox with the picture format "4:3".
- The sound can have a short gap now and then (shots, the ending movie on some devices).
- Debug build's discs: Ashley can walk through the armor statues (the prototype's data has no collision there).
- Some controllers' left stick can make Leon stutter while walking (the D-pad does not): try a higher stick range or dead zone; if it still stutters, walk with the stick for 30 seconds and send a report.
- Phones with only small processor cores (for example Samsung Galaxy A13): the game runs slower than normal, so cutscenes run behind their voices. Frame skip cannot help there.

## Update

Install `CubeEvil4-0.99.3-rc.apk` over an earlier version; discs, saves and settings stay.

**Found a bug?** Keep "Record the error log" on (app menu → Management → Error log, on by default) and send
the report right away, without closing the game first: app menu (SELECT) → Management → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
